evosolve: an algorithm that invented itself

a search process, given only primitive math operations, invented a numerical algorithm for solving linear systems. it landed on conjugate gradient, a method humans took decades to develop. watch it run below, live, against the older methods it beats.

the algorithm the search wrote

assembled from random building blocks, then refined. this is exactly conjugate gradient:

beta_k  = (r . r) / (r . r)_prev        # fletcher reeves
alpha_k = (r . r) / (d . a d)           # optimal step length
d_k     = r_k + beta_k * p_(k-1)        # search direction
x_(k+1) = x_k + alpha_k * d_k           # update  ( r_k = b - a x_k )

the same engine also rediscovers gcr for nonsymmetric systems and discovers polynomial preconditioners. full write up and the honest results (including where it does not beat the state of the art) are in the readme.
